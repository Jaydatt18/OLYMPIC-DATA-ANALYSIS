🏅 Olympic Analysis Project
📌 Overview

This project is a comprehensive analysis of the Olympic Games dataset 🏟️.
It explores patterns, trends, and insights related to athletes, countries, sports, and medals over time.

📂 Dataset
Source: https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results

Features include:

  👤 Athlete information (Name, Age, Sex, etc.)
  
  🌍 Country/NOC (National Olympic Committee)
  
  📅 Year and Season of the Olympics
  
  🏸 Sport and Event
  
  🥇🥈🥉 Medal Won
  

🎯 Project Goals

  📊 Analyze medal trends over the years
  
  🏆 Identify top-performing countries & athletes
  
  👨‍🦰👩‍🦰 Study gender-based participation and performance
  
  🏐 Explore sport-wise performance patterns
  
  📈 Visualize insights with interactive charts
  

🛠️ Technologies Used

  🐍 Python
  
  🧮 Pandas & NumPy (data handling)
  
  📊 Matplotlib & Seaborn (visualizations)
  
  🌐 Plotly (interactive dashboards)
  
  📓 Jupyter Notebook
  

⭐ Key Features

  🥇 Medal Analysis: Trends by country, sport, and year
  
  👨‍🎓 Athlete Analysis: Top players & performance metrics

  ⏳ Trend Analysis: Long-term Olympic patterns
  
  📊 Interactive Visuals with Plotly
  
  💡 Insightful observations & conclusions
